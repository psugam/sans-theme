# DEPLOYMENT 
Static sites generated by Hugo using  *sans* theme can be deployed using various services. Configuration for some popular services for hosting static sites like Github pages, Cloudeflare pages, 

#### Pagefind 
``` npx pagefind --site public --output-path public\pagefind```
#### ExampleSite
```hugo server --themesDir ../.. --buildDrafts```

## GITHUB PAGES

If you are hosting your static site in your-username.github.io change the hugo.github.toml to hugo.toml in the run command of hugo. If you are hosting the site in your-username.github.io/repo-name/ change the value of baseURL in hugo.github.toml to `your-username.github.io/repo-name`

```
# Sample workflow for building and deploying a Hugo site with Pagefind to GitHub Pages
name: Deploy Hugo site with Pagefind to Pages

on:
  # Runs on pushes targeting the default branch
  push:
    branches: ["master"]

  # Allows manual trigger from the Actions tab
  workflow_dispatch:

# Permissions for deployment
permissions:
  contents: read
  pages: write
  id-token: write

# Ensure only one deploy at a time
concurrency:
  group: "pages"
  cancel-in-progress: false

# Default to bash shell
defaults:
  run:
    shell: bash
# hugo --minify --baseURL "${{ steps.pages.outputs.base_url }}/"
jobs:
  build:
    runs-on: ubuntu-latest
    env:
      HUGO_VERSION: 0.146.0   
      NODE_VERSION: 20        
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4
        with:
          submodules: recursive  # for theme inclusion

      - name: Install Hugo CLI
        run: |
          wget -O ${{ runner.temp }}/hugo.deb https://github.com/gohugoio/hugo/releases/download/v${HUGO_VERSION}/hugo_extended_${HUGO_VERSION}_linux-amd64.deb
          sudo dpkg -i ${{ runner.temp }}/hugo.deb

      - name: Install Dart Sass
        run: sudo snap install dart-sass

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}

      - name: Setup GitHub Pages
        id: pages
        uses: actions/configure-pages@v5

      - name: Install Node dependencies (Pagefind)
        run: |
          npm install pagefind

      - name: Build site with Hugo
        env:
          HUGO_CACHEDIR: ${{ runner.temp }}/hugo_cache
          HUGO_ENVIRONMENT: production
        run: |
          hugo --minify --config hugo.github.toml

      - name: Run Pagefind indexing
        run: |
          npx pagefind --site public --output-path public/pagefind

      - name: Upload site artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./public

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

## VERCEL DEPLOYMENT

``` {
  "builds": [
    {
      "src": "package.json",
      "use": "@vercel/static-build",
      "config": {
        "distDir": "public"
      }
    }
  ],
  "framework": null,
  "buildCommand": "npm run build",
  "outputDirectory": "public",
  "cleanUrls": true,
  "trailingSlash": false,
  "ignoreCommand": "git diff --quiet HEAD^ HEAD ./"
}
 ```

## NETLIFY 
```
 [build]
  publish = "public"
  command = "hugo --minify && npx pagefind --site public --output-path public/pagefind"

[build.environment]
  HUGO_VERSION = "0.146.0"
  NODE_VERSION = "20"

[[redirects]]
  from = "/pagefind/*"
  to = "/pagefind/:splat"
  status = 200

```
